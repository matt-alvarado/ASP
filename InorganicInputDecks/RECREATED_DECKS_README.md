# Recreated ASP input decks: Williams, Otavi, Alaska, Timbavati

Generated by `build_decks.py` (all choices are in that script; change a mapping or number and rerun). Each case folder holds a full
`InorganicInputDecks/` set; only `GasPhaseChems.in`, `AerosolModes.in`, `EnvAerosolModes.in` (the files you lost) and `ASPInputDeck.in`
differ from the current Williams template deck.  `lumped_initial_conditions.csv` shows how every paper species was summed into an ASP
species; `species_mapping_proposed.csv` is the full mapping with confidence.

## Judgement calls applied (change in `build_decks.py` if you disagree)
- Lumping is mole-for-mole into the ASP/RACM2 lumps (HC5, HC8, OLT, OLI, KET), as you chose.
- i-pentane and 2-methyl-butane are the same compound but both appear in the Timbavati table; both are added into HC5.
- Xylenes split m/p/o = 0.56/0.15/0.29 (the fractions in the Williams deck); terpenes split 50/50 between API and LIM (CACM half BIOL, half BIOH).
- C4H8 -> 1-Butene; C3H6O -> OLT; octenes, styrene -> OLT; ethylbenzene -> TOL; methyl formate and methyl acetate -> KET; C3H6O2 -> ACETOL;
  butanols -> NBUTOL; cyclopentanol -> ROH; C3-C7 aldehydes -> ALD; N2O and PAHs omitted (no ASP species; N2O inert).
- CO2 is not in the Otavi/Timbavati tables: set to 380,000 ppb (initial and background). Inert here.
- Environment settings in `ASPInputDeck.in` are from the papers: T, P, RH; start time (UT); run length; mixing parameter tau = y0^2/(4 Ky)
  (Otavi 156.25 s, Alaska 1387.1 s, Timbavati 142.86 s, Williams 106.87 s); "hetero" number/radius.

## NOT recreated: PhotoRates.in  (this matters)
All four case folders still contain the shared template `PhotoRates.in`.  Its table is zero at UT 10-21 h (solar zenith angle > 100 deg), so with the
paper start times (Williams 19:00, Otavi 11:00, Timbavati 08:45 UT) there is little or no photolysis.  Test runs load and finish, but O3 and OH stay near
zero for Timbavati and ozone growth is far too small for Williams.  Case-specific TUV output (96 quarter-hour rows, 50 columns) is needed.
